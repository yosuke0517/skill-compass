# Skill Compass

Skill Compassは、AI支援時代のエンジニアに向けた実務判断力の学習基盤です。

レビュー済みの実務ケース、ユーザー別のTodayと成長記録、Podcast、X技術ニュースを正本として保持し、Webと能力を限定したMCPから利用できます。ChatGPT Voice/Liveを教師の会話面として活かしつつ、Webアプリも継続して提供します。
